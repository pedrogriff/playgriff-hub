## 🌟 Interactive Systems Featured

1. **⚡ PeopleAgentMesh (Flagship)**: Production-grade multi-agent orchestration and human-in-the-loop (HITL) governance platform for sensitive People Operations across Brazil 🇧🇷 (CLT/LGPD), United States 🇺🇸 (FLSA/Title VII), and Canada 🇨🇦 (PIPEDA). Features bi-directional PII/SPII tokenization, statutory compliance verifiers, interactive Slack approval cards, and CI golden eval quality gates.
2. **💎 NextComp Workbench**: Interactive salary range modeling engine with real-time midpoint & spread % recalculation, Incumbent Impact Summary telemetry (Green-Circle correction budget, Red-Circle governance, and Department Compa-Ratios), and full roster drilldown.
3. **🤖 CompFlow Platform**: Autonomous compensation review calibration copilot with live tool-calling inspection and state machine governance (20,000+ audits/sec).
4. **📈 VestingSim Engine**: Exact share conservation 48-month bar chart (Largest Remainder Method) + Real-Time Monte Carlo price trajectory canvas simulation.
5. **🧠 AlgoCore CS Lab**: Live queue race comparing $O(N^2)$ array front shifts vs $O(1)$ ring buffer execution, plus $O(\log N)$ AVL tree salary percentile slider.
6. **☸️ Homelab Kubernetes**: Immutable Talos Linux bare-metal cluster architecture and GitOps pipeline.

## 🚀 Local Development

To run locally:

```bash
cd playgriff-hub
python3 -m http.server 8080
```

Open `http://localhost:8080` in any web browser.
